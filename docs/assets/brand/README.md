# Chronikwerk Brand Assets

These repository-owned SVGs are the canonical public exports of the Chronikwerk
folio-and-timeline identity.

- `chronikwerk-mark.svg`: standalone full-colour mark for light surfaces.
- `chronikwerk-mark-monochrome.svg`: current-colour mark for one-colour contexts.
- `chronikwerk-lockup.svg`: horizontal mark and wordmark for documentation surfaces.

Keep the wordmark legible, preserve the SVG view box, and do not recolour the full-colour
export. In product UI, use the mark decoratively beside selectable text. Do not animate,
emboss, distort, enclose in a seal, or use the identity to imply certification.
